### R1 — `frecuenciaCaracteres(texto)` — ✅ Completado (1 fallo)

**❌ Error:** `return lista;` DENTRO del for → la función salía en la primera iteración devolviendo solo `{h:1}`.

!!! failure "❌ Código de Pau (primer intento)"

    ```js
    function frecuenciaCaracteres(texto) {
      let lista = {};
      for (let i = 0; i < texto.length; i++) {
        if (texto[i] === " ") continue;
        if (lista[texto[i]])
          lista[texto[i]]++;
        else
          lista[texto[i]] = 1;
        return lista;  // sale en la primera iteración
      }
    }
    ```

!!! success "✅ Versión corregida (return fuera del loop)"

    ```js
    function frecuenciaCaracteres(texto) {
      let lista = {};
      for (let i = 0; i < texto.length; i++) {
        if (texto[i] === " ") continue;
        if (lista[texto[i]])
          lista[texto[i]]++;
        else
          lista[texto[i]] = 1;
      }
      return lista;  // fuera del loop, al nivel de la función
    }
    ```

🧠 **Lección:** un `return` dentro de un loop solo sirve para salir ANTES de tiempo (encontré lo que buscaba / error). Si querés el resultado de recorrer TODO, va después de la llave del for. Antídoto: trace mental antes de guardar — si en la 1ª vuelta ya salís de la función, el loop no termina.

### R2 — `agruparPorLetra(palabras)` — ✅ Completado (1 detalle)

**❌ Detalle:** `if (palabras[i][0] === " ") continue;` — guard de espacios "copiado" del R1, donde SÍ tenía sentido. Acá el enunciado no lo pide.

!!! failure "❌ Código de Pau (detalle a pulir)"

    ```js
    function agruparPorLetra(palabras) {
      let lista = {};
      if (palabras.length === 0) return null;
      for (let i = 0; i < palabras.length; i++) {
        if (palabras[i][0] === " ") continue;  // sobra — no lo pide el enunciado
        if (lista[palabras[i][0]])
          lista[palabras[i][0]].push(palabras[i]);
        else
          lista[palabras[i][0]] = [palabras[i]];
      }
      return lista;
    }
    ```

!!! success "✅ Versión corregida (sin guard extra + naming)"

    ```js
    function agruparPorLetra(palabras) {
      let grupos = {};
      if (palabras.length === 0) return null;
      for (let i = 0; i < palabras.length; i++) {
        if (grupos[palabras[i][0]])
          grupos[palabras[i][0]].push(palabras[i]);
        else
          grupos[palabras[i][0]] = [palabras[i]];
      }
      return grupos;
    }
    ```

🧠 **Lección:** código extra = comportamiento imprevisto. El código debe hacer exactamente lo que pide el enunciado, ni más ni menos. Naming: objeto de grupos = `grupos`, no `lista`.

### R3 — `ordenarPorPrecio(productos)` — ✅ Completado (2 fallos)

**❌ Fallo 1:** swap usaba `i`/`i+1` mientras la condición comparaba `j`/`j+1` — "lo que comparás, lo que intercambiás" deben ser los MISMOS índices.
**❌ Fallo 2:** loop interno `j < productos.length` sin `- 1` → `productos[length]` es `undefined` y `undefined.precio` revienta (mismo gotcha que Fallo 7 `estaOrdenado`).

!!! failure "❌ Código de Pau (2° intento)"

    ```js
    function ordenarPorPrecio(productos) {
      let valor = "";
      for (let i = 0; i < productos.length; i++) {
        for (let j = 0; j < productos.length; j++) {  // falta - 1
          if (productos[j].precio > productos[j + 1].precio) {
            valor = productos[i];                     // compara j pero swapea i
            productos[i] = productos[i + 1];
            productos[i + 1] = valor;
          }
        }
      }
      return productos;
    }
    ```

!!! success "✅ Versión corregida (swap coherente + length - 1)"

    ```js
    function ordenarPorPrecio(productos) {
      let valor = "";
      for (let i = 0; i < productos.length; i++) {
        for (let j = 0; j < productos.length - 1; j++) {
          if (productos[j].precio > productos[j + 1].precio) {
            valor = productos[j];
            productos[j] = productos[j + 1];
            productos[j + 1] = valor;
          }
        }
      }
      return productos;
    }
    ```

🧠 **Lección:** comparar adyacentes → loop hasta `length - 1`. El `i` del loop externo no se usa: es la "máquina de repeticiones" — cada pasada empuja el mayor al final (burbuja). Una pasada no alcanza. Optimización: `j < length - 1 - i`.

### V1 — `tieneAlgo(lista)` — ✅ Completado (1 fallo)

**Error — "al menos uno" ≠ "exactamente uno":** el enunciado pedía `true` si hay **al menos un** elemento. `=== 1` solo da `true` cuando hay exactamente 1: `tieneAlgo([1, 2])` devolvía `false` (length 2).

!!! failure "❌ Código de Pau (primer intento)"

    ```js
    function tieneAlgo(lista) {
      return lista.length === 1 ? true : false;
    }
    ```

!!! success "✅ Versión corregida (al menos uno = length > 0)"

    ```js
    function tieneAlgo(lista) {
      return lista.length > 0;
    }
    ```

🧠 **Lección:** "al menos" siempre es `>` o `>=`; "exactamente" es `===`. Tabla: "al menos un elemento" → `length > 0` · "exactamente uno" → `length === 1` · "vacío" → `length === 0`. Bonus: `cond ? true : false` es redundante — la condición YA es un booleano.
