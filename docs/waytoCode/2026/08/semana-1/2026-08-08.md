### V4 — `precioTotalPerecederos(items)` — ✅ Completado (1 fallo)

**❌ Error:** en el caso de "no perecedero", NUNCA tocaba el acumulador — devolvía el elemento en vez del número:

!!! failure "❌ Código de Pau (fallo corregido)"

    ```js
    function precioTotalPerecederos(items) {
      let sumaTotal = items.reduce((acum, n) => {
        if (n.tipo === "perecedero") return acum + n.precio;
        return n;   // ❌ acá rompe: devuelve el elemento, no el acumulador
      }, 0);
      return sumaTotal;
    }
    ```

!!! success "✅ Versión corregida (acumulador siempre se devuelve)"

    ```js
    function precioTotalPerecederos(items) {
      let sumaTotal = items.reduce((acum, n) => {
        if (n.tipo === "perecedero") return acum + n.precio;
        return acum + 0;   // ✅ no perecedero → suma 0, acumulador intacto
      }, 0);
      return sumaTotal;
    }
    ```

🧠 **Lección:** el `return acum` va SIEMPRE en el callback de reduce, se entre en el `if` o no. Si en la vuelta "rechazada" devolvés otra cosa (el elemento, `undefined`), el acumulador se corrompe y toda la cadena de suma se rompe. "No perecedero" = "sumo 0". Es el mismo `if` dentro del loop que ya usabas en `promedioAprobados`, versión reduce.
