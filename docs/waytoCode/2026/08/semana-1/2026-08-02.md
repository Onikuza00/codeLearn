### E1 — `dobles(numeros)` — ✅ Sin errores

```js
function dobles(numeros) {
  return numeros.map(n => n * 2)
}
```

🧠 **`map` correcto:** devuelve array nuevo con la transformación. Detalle de estilo: JS no necesita `;` al final, pero el proyecto los usa — consistencia.

---

### E2 — `preciosDe(productos)` — ✅ Sin errores

```js
function preciosDe(productos) {
  return productos.map(n => n.precio);
}
```

🧠 **Extraer propiedad con `map`:** correcto. 💡 *Naming:* acá `n` es un objeto producto, no un número. Mejor `p` o `producto` — el nombre del parámetro debe decir qué es.

---

### E3 — `soloPares(numeros)` — ✅ Sin errores

```js
function soloPares(numeros) {
  return numeros.filter(n => n % 2 === 0);
}
```

🧠 **`filter` con predicado perfecto:** `n % 2 === 0` devuelve `true`/`false` y `filter` conserva solo los pares.

---

### E4 — `disponibles(productos)` — ✅ Sin errores

```js
function disponibles(productos) {

  return productos.filter(n => n.stock > 0);
}
```

🧠 **`filter` sobre objetos:** correcto. Dos detalles menores: línea en blanco de más al inicio, y mismo naming que E2 (`n` → mejor `p`).

---

### E5 — `totalCarrito(items)` — ✅ Sin errores

```js
function totalCarrito(items) {
  let suma = 0;
  items.forEach(n => {
    suma += n.precio * n.cantidad;
  })
  return suma;
}
```

🧠 **`forEach` como acumulador:** correcto — el callback no devuelve nada, el resultado sale de `suma`. 💡 *Naming:* `n` es un item, mejor `item`.

### E6 — `promedioAprobados(estudiantes)` — ❌ → 🔁 2 errores

!!! failure "❌ Código de Pau (primer intento)"

    ```js
    function promedioAprobados(estudiantes) {
      if (!estudiantes.filter(n => n.nota >= 5)) return null;
      let media = 0;
      let cont = 0;
      estudiantes.forEach(estudi => {
        media += estudi.nota;
        cont++;
      })
      return media / cont;
    }
    ```

**Error 1 — el `if` nunca dispara:** `filter()` devuelve un **array**, y los arrays (incluso vacíos) son **siempre truthy**. `![]` es `false`, así que el `return null` jamás corre. Para saber si un array quedó vacío hay que preguntar por su `.length`.

**Error 2 — suma a TODOS, no solo aprobados:** el `forEach` suma y cuenta todos los estudiantes. Para `[Ana 7, Luis 4, Pau 6]` da `(7+4+6)/3 = 5.67` en vez de `6.5`. La condición `nota >= 5` existe en el `filter` de arriba, pero ese resultado no se usa.

!!! success "✅ Versión corregida (mismo estilo, condicional dentro del loop)"

    ```js
    function promedioAprobados(estudiantes) {
      let suma = 0;
      let cont = 0;
      estudiantes.forEach(estudi => {
        if (estudi.nota >= 5) {
          suma += estudi.nota;
          cont++;
        }
      });
      return cont === 0 ? null : suma / cont;
    }
    ```

🧠 **Es el mismo patrón que E12 `mediaAprobados` (30/07):** filtrar "implícito" dentro de un solo loop con `if`, y después `if (cont === 0) return null`. La pista estaba en tu propio código de la semana pasada — lo habías dominado. 👊

🧠 **Lección nueva — arrays son truthy:** `[]`, `[1]`, `["a"]` → todos evaluan a `true`. Nunca uses `!array` para detectar vacío. Usá `array.length === 0`.
