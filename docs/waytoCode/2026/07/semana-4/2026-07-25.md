| Concepto | Error | Solución | Por qué |
|----------|-------|----------|---------|
| Variable `--c-bluek` | No existe en `:root` | Usar `--c-blue-dark` o `--c-blue` | CSS ignora variables undefined, la propiedad se cae sin errores |

| `line-height` en descripción | `1.2` | `1.5` | `1.2` es para títulos, `1.5` para párrafos mejora legibilidad |

### Features

| Concepto | Error | Solución | Por qué |
|----------|-------|----------|---------|
| `box-shadow` alpha | `rgba(0,0,0,1)` sólido | `rgba(0,0,0,0.5)` base / `0.8` hover | Una sombra opaca no es sombra, es una mancha |

| `--tr-verylong` (600ms) en hover | 600ms para transform | Usar `--tr-normal` (200ms) | Los hovers deben responder rápido |

### Pricing

| Concepto | Error | Solución | Por qué |
|----------|-------|----------|---------|

### Contacto

| Concepto | Error | Solución | Por qué |
|----------|-------|----------|---------|
| Conexión label-input | `for="nom"` con `name="nom"` | `for="nom"` con `id="nom"` | `for` matchea con `id`, no con `name` |

## 🐛 Fallos JS detectados y lecciones

### 1. `sumarPares` — Acumular vs contar

```js
// ❌ Pau:
if (i % 2 == 0) suma++;    // cuenta cuántos pares hay

// ✅ Debe ser:
if (i % 2 == 0) suma += i; // suma el valor de cada par
```

**Lección:** `suma++` suma 1 (contar). `suma += i` suma cualquier valor (acumular). Son distintos.

### 2. `contarPalabras` — Off-by-one

```js
// ❌ Pau:
return numero - 1;  // 1 espacio → devuelve 0

// ✅ Debe ser:
return numero + 1;  // 1 espacio → devuelve 2
```

**Lección:** palabras = espacios + 1. Y early return si string vacío.

### 3. `filtrarMayores` — `.length` en números

```js
// ❌ Pau:
if (item.length > limite)  // los números no tienen .length

// ✅ Debe ser:
if (item > limite)
```

**Lección:** `.length` es para strings y arrays. En números da `undefined`.

### 4. `esPalindromo` — `.reverse()` en strings

```js
// ❌ Pau:
string.reverse()  // no existe en strings

// ✅ Debe ser:
string.split("").reverse().join("")
```

**Lección:** `.reverse()` es de arrays. Convertí antes.

### 5. `contarMayusculas` — Espacios colados

```js
// ❌ Pau:
if (letra === letra.toUpperCase()) contador++;  // espacios también cuentan

// ✅ Debe ser:
if (letra === letra.toUpperCase() && letra !== " ") contador++;
```

**Lección:** `" ".toUpperCase() === " "` es true. Filtrar siempre.

### 6. `numerosImpares` — Off-by-one en loop

```js
// ❌ Pau:
for (let i = 1; i < n; i++)  // no incluye a n

// ✅ Debe ser:
for (let i = 1; i <= n; i++) // incluye a n
```

**Lección:** `<` excluye, `<=` incluye. Preguntar siempre "¿llego hasta n?"

### 7. `estaOrdenado` — Condición imposible

```js
// ❌ Pau:
if (array[i] + 1 < array[i]) return false;  // NUNCA es true

// ✅ Debe ser:
if (array[i] > array[i + 1]) return false;
```

**Lección:** `n + 1` siempre es mayor que `n`. Comparar cada elemento con el siguiente usando `array[i] > array[i+1]`.

### 8. `esPrimo` — Condición siempre true

```js
// ❌ Pau:
if (numero % numero == 0 && numero % 1 == 0) return true;  // siempre true

// ✅ Debe ser:
if (n < 2) return false;
for (let i = 2; i < n; i++) {
  if (n % i === 0) return false;  // encontró divisor
}
return true;
```

**Lección:** `n % n == 0` es cierto para **todo** número. No sirve para detectar primos.

### 9. `limpiarEspacios` — Contador global

```js
// ❌ Pau: contador global que nunca se reinicia
let count = 0;
if (letra == " ") count++;
if (letra == " " && count < 1) ...  // count < 1 NUNCA se cumple

// ✅ Debe ser: mirar el caracter anterior
if (string[i] === " " && string[i - 1] === " ") continue;
```

**Lección:** No uses contador global para detectar repetición local. Mirá `string[i-1]`.

## 🔴 Debilidades JS

| # | Problema | Lección |
|---|----------|---------|
| 1 | **Off-by-one** | Preguntar siempre "¿incluyo o excluyo el límite?" (`<` vs `<=`) |
| 2 | **`!` vs `!==`** | `!` niega booleano, `!==` pregunta "es distinto". No confundirlos |
| 3 | **`.length` en números** | Solo strings y arrays tienen `.length` |
| 4 | **Contexto local** | Usar `array[i-1]` o `string[i-1]` en vez de contadores globales |
| 5 | **Primos** | Si encontrás divisor → no es primo. Si terminás el loop → es primo |
| 6 | **Precedencia** | Usar paréntesis ante la duda (`(i % 2 !== 0)`) |
| 7 | **Casos borde** | Pensar: string vacío, array de 1 elemento, espacios, n=1, n=0 |
