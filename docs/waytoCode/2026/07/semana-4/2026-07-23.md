# 2026-07-23 — CSS Grid { .section-responsive }

> ⏱ ~2h · Examen Nexus: Sección 4 (Layout) + Sección 5 (Pricing)

## 📋 Resumen

Sesión práctica con el examen **Nexus Agency**. Trabajamos dos secciones del CSS:

### Sección 4 — Layout de página (Grid areas + BEM)

- Implementado `.layout` con `grid-template-areas`
- Mobile: stacked (header → aside → main → footer) ✅
- Desktop (>768px): header full, main + aside, footer full ✅
- Creado `<aside class="sidebar">` con categorías ✅
- BEM en sidebar, `:focus-visible`, transiciones ✅
- **Pendiente:** Portfolio (4 proyectos con `repeat(2, 1fr)` dentro de `<main>`)

### Sección 5 — Pricing (Grid + :has() + CQ)

- Grid responsive Mobile First ✅
- `:has(.pricing__badge)` para destacar card "Más popular" ✅
- `:focus-visible` en CTAs ✅
- **Problemas resueltos:**
  - `display: inline-size` corregido (no existe ese valor)
  - Media query movida a `>= 768px` para que mobile se vea en 1 columna
  - `container-type` ubicado correctamente
- **Pendiente:** BEM sigue mezclado (`.price` vs `.pricing`, `.cards__price` vs `.pricing__card`)

### Conceptos clave vistos

- `grid-template-areas` con media queries
- `container-type: inline-size` vs `@container`
- `:has()` para estilado condicional
- Diferencia entre `@media` (layout exterior) y `@container` (interior del componente)
- Mobile First: base = mobile, media query con `>= 768px` para desktop

## 🔴 Debilidades

| # | Problema | Lección |
|---|----------|---------|
| 1 | **BEM inconsistente** — mezcla `.price`, `.cards__price`, `.pricing__badge` (3 bloques distintos para una misma sección) | Elegir un bloque (`pricing`) y mantenerlo en todos los elementos hijos |
| 2 | **`display: inline-size`** — no existe como valor de display | El valor correcto es `display: flex` + `container-type: inline-size` |
| 3 | **`@container` estilando al padre** — intentó cambiar `.price` desde dentro de un container anidado | `@container` solo estila **descendientes** del container, no al contenedor mismo ni a sus padres |
| 4 | **Breakpoint a 400px** — en móviles modernos (375-430px) se veían 3 columnas en mobile | Los móviles modernos miden >400px. Usar breakpoint de 768px para evitar solapamiento |
| 5 | **Clases `.cards__price` duplicadas** — el segundo bloque pisaba al primero | No duplicar selectores. Un solo `.cards__price` con todas las propiedades |
