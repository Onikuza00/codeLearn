### E9 — `frecuenciaCaracteres(texto)`

!!! failure "❌ Código de Pau (primer intento)"

    ```js
    function frecuenciaCaracteres(text) {
        if (text.length === 0) return null;
        let frase = {};
        let cantidad = 0;
        let valor = "";
        let palabra = text.trim().split("");
        for (let i = 0; i < palabra.length; i++) {
            if (palabra[i] !== " ") {
                valor = palabra[i];
                if (palabra[i] === valor) cantidad++;  // ← MAL: letra === letra
            }
            frase = [valor, cantidad];                 // ← MAL: pisás el objeto
            valor = "";
            cantidad = 0;
        }
        return frase;
    }
    ```

Dos problemas:
1. `palabra[i] === valor` es comparar la letra **contra sí misma**. Siempre true.
2. `frase = [valor, cantidad]` convierte el objeto en array y lo pisas cada vuelta.

!!! success "✅ Versión corregida"

    ```js
    function frecuenciaCaracteres(text) {
        if (text.length === 0) return null;
        let frase = {};
        let palabra = text.split("");
        for (let i = 0; i < palabra.length; i++) {
            if (palabra[i] === " ") continue;
            frase[palabra[i]] ? frase[palabra[i]]++ : frase[palabra[i]] = 1;
        }
        return frase;
    }
    ```

🧠 **Objetos como contadores de frecuencia.** El patrón `objeto[clave] ? objeto[clave]++ : objeto[clave] = 1` te deja contar ocurrencias sin variables auxiliares. Cada clave del objeto es un elemento distinto, cada valor es su cuenta. Sin `push`, sin variables sueltas.

### E10 — `ordenarPorPrecio(productos)` [3 intentos]

!!! failure "❌ Intento 1 — swap al revés + variable referencia errónea"

    ```js
    function ordenarPorPrecio(productos) {
        let temporal = productos[0];         // ← innecesario
        for (let i = 0; i < productos.length; i++) {
            if (productos[i] < productos[i - 1]) {    // ← compara objetos, no precios
                temporal = productos[i];
                productos[i - 1] = productos[i];       // ← pisa izquierda con derecha
                productos[i] = temporal;               // ← recupera derecha (swap mal)
            }
        }
    }
    ```

    Tres problemas:
    1. `productos[i] < productos[i - 1]` compara objetos enteros, no `.precio`. JS no sabe comparar objetos.
    2. El swap está invertido: pisa A con B y después recupera B. Termina con `[B, B]`.
    3. `i = 0` → en la primera iteración `productos[-1]` es `undefined` → error.

!!! failure "❌ Intento 2 — swap corregido pero falta doble for"

    ```js
    function ordenarPorPrecio(productos) {
        let temporal;
        for (let i = 1; i < productos.length; i++) {   // ← solo una pasada
            if (productos[i].precio < productos[i - 1].precio) {
                temporal = productos[i];
                productos[i] = productos[i - 1];
                productos[i - 1] = temporal;
            }
        }
    }
    ```

    Swap correcto ✅. Pero **una sola pasada no alcanza**: el elemento más chico solo sube un lugar por pasada. Si está al fondo, necesita `n-1` pasadas.

!!! success "✅ Versión final — bubble sort completo"

    ```js
    function ordenarPorPrecio(productos) {
        let temporal;
        for (let j = 0; j < productos.length; j++) {        // ← pasadas externas
            for (let i = 1; i < productos.length; i++) {    // ← barrido interno (swap)
                if (productos[i].precio < productos[i - 1].precio) {
                    temporal = productos[i];
                    productos[i] = productos[i - 1];
                    productos[i - 1] = temporal;
                }
            }
        }
        return productos;
    }
    ```

🧠 **Lección del día — Bubble Sort**

El bubble sort necesita **dos fors anidados**:

| For | Rol | Cuántas veces |
|-----|-----|---------------|
| **Interno** (`i`) | Compara adyacentes y swapea si toca | Recorre el array entero |
| **Externo** (`j`) | Repite el barrido interno | `length` veces (o `length-1`) |

Sin el for externo, un elemento que tiene que subir 3 posiciones solo sube 1 por pasada. Necesitás repetir el barrido. El nombre "bubble" viene de que los elementos **flotan hacia arriba** como burbujas, un lugar por vez.

🧠 **El patrón swap** (tres líneas):

```js
temporal = array[i];
array[i] = array[i - 1];
array[i - 1] = temporal;
```

1. Guardás el que vas a pisar
2. Pisás con el otro
3. Recuperás el guardado en la posición contraria

🧠 **Error tonto:** escribir `array.length` en vez de `productos.length`. `array` no existe → `ReferenceError`.

### E11 — `agruparPorLetra(palabras)`

!!! failure "❌ Código de Pau (primer intento)"

    ```js
    function agruparPorLetra(lista) {
        if (lista.length === 0) return null;
        let listaOrdenada;                              // ← sin inicializar
        let texto = lista.split(" ");                   // ← array no tiene split
        for (let i = 0; i < texto.length; i++) {
            if (texto[i] === " ") continue;             // ← en array no hay espacios
            let primerCarc = texto[i][0];
            listaOrdenada[primerCarc] ? listaOrdenada[primerCarc].push(texto[i]) : listaOrdenada[primerCarc] = [texto[primerCarc]];
        }
        return listaOrdenada;
    }
    ```

    Tres errores:
    1. `lista` ya es un array; no necesita `split(" ")`.
    2. `listaOrdenada` declarada sin valor → `undefined[clave]` explota.
    3. El ternario en el `else` hace `[texto[primerCarc]]` en vez de `[texto[i]]`.

!!! success "✅ Versión corregida"

    ```js
    function agruparPorLetra(lista) {
        if (lista.length === 0) return null;
        let listaOrdenada = {};
        for (let i = 0; i < lista.length; i++) {
            let primerCar = lista[i][0];
            listaOrdenada[primerCar] ? listaOrdenada[primerCar].push(lista[i]) : listaOrdenada[primerCar] = [lista[i]];
        }
        return listaOrdenada;
    }
    ```

🧠 **Objeto como agrupador.** Mismo patrón que E9 (objeto-contador) pero acumulando arrays con `.push()` en vez de `++`.

### E12 — `mediaAprobados(estudiantes)`

!!! success "✅ Sin errores — primera vez correcto"

    ```js
    function mediaAprobados(estudiantes) {
        if (estudiantes.length === 0) return null;
        let aprobados = 0;
        let suma = 0;
        for (let i = 0; i < estudiantes.length; i++) {
            if (estudiantes[i].nota >= 5) {
                aprobados++;
                suma += estudiantes[i].nota;
            }
        }
        if (aprobados === 0) return null;
        return suma / aprobados;
    }
    ```

🧠 **Filter implícito:** en vez de filtrar primero y después hacer la media, lo hace todo en un solo loop: si aprueba, sumás y contás. Después dividís.

### E13 — `eliminarDuplicados(array)`

!!! success "✅ Sin errores"

    ```js
    function eliminarDuplicados(array) {
        let temporal = [];
        for (let i = 0; i < array.length; i++) {
            if (temporal.includes(array[i])) continue;
            temporal.push(array[i]);
        }
        return temporal;
    }
    ```

🧠 **`includes()` como guardián.** Si el elemento ya está en el resultado, `continue`. Si no, `push`. Alternativa: objeto `vistos{}` (más eficiente para arrays grandes).

### E14 — `sumarMatriz(matriz)`

!!! success "✅ Sin errores"

    ```js
    function sumarMatriz(matriz) {
        let suma = 0;
        for (let i = 0; i < matriz.length; i++) {
            for (let j = 0; j < matriz[i].length; j++) {
                suma += matriz[i][j];
            }
        }
        return suma;
    }
    ```

🧠 **Doble for con matrices.** El externo recorre filas, el interno recorre columnas. `matriz[i][j]` accede a cada elemento. Misma estructura que bubble sort pero sin swap.
