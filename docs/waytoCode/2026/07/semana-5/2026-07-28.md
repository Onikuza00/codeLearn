### E1 — `extraerDominio(email)`

!!! failure "❌ Código de Pau"

    ```js
    function extraerDominio(email) {
        let pos = email.indexOf("@");
        return email.slice(pos + 1);  // ← MAL: si no hay @, pos = -1 → slice(0)
    }
    ```

Si el email no tiene `@`, `indexOf` devuelve `-1`. `slice(-1 + 1)` = `slice(0)` → te devuelve el string entero.

!!! success "✅ Versión corregida"

    ```js
    function extraerDominio(email) {
        if (typeof email !== "string" || email.length === 0) return null;
        let pos = email.indexOf("@");
        if (pos === -1) return null;
        return email.slice(pos + 1);
    }
    ```

🧠 **Early return + validar antes de actuar.** Primero preguntás "¿esto es válido?", si no lo es, cortás. Después ejecutás.

### E2 — `esSlugValido(slug)`

!!! failure "❌ Código de Pau"

    ```js
    function esSlugValido(slug) {
        let valido = true;
        for (let i = 0; i < slug.length; i++) {
            let c = slug[i];
            if (c >= "a" && c <= "z") continue;
            if (c >= "0" && c <= "9") continue;
            if (c === "-") continue;
            valido = false;               // ← MAL: marca pero sigue recorriendo
        }
        return valido;
    }
    ```

Sigue recorriendo todo el string aunque ya encontró un caracter inválido. Es el mismo patrón que `estaOrdenado` del 25/07.

!!! success "✅ Versión corregida"

    ```js
    function esSlugValido(slug) {
        if (slug.length === 0) return false;
        for (let i = 0; i < slug.length; i++) {
            let c = slug[i];
            if (c >= "a" && c <= "z") continue;
            if (c >= "0" && c <= "9") continue;
            if (c === "-") continue;
            return false;  // corta acá
        }
        return true;
    }
    ```

🧠 **Early rejection vs flag.** No acumulés evidencia para después decidir. En el momento que encontrás algo inválido, cortá con `return`. Es más rápido, más claro, y no arrastrás estado.

### E4 — `productoMasCaro(productos)`

!!! failure "❌ Código de Pau"

    ```js
    function productoMasCaro(productos) {
        let max = 0;           // ← MAL: asume precios positivos
        let masCaro = "";
        productos.forEach(item => {
            if (item.precio > max) {
                max = item.precio;
                masCaro = item.nombre;
            }
        });
        if (masCaro === "") return null;
        return masCaro;
    }
    ```

`let max = 0` asume que los precios son positivos. Si todos los productos valen menos de 0, ningún `item.precio > 0` se cumple y devuelves `null` aunque haya productos.

!!! success "✅ Versión corregida"

    ```js
    function productoMasCaro(productos) {
        if (productos.length === 0) return null;
        let maxPrecio = productos[0].precio;
        let maxNombre = productos[0].nombre;
        for (let i = 1; i < productos.length; i++) {
            if (productos[i].precio > maxPrecio) {
                maxPrecio = productos[i].precio;
                maxNombre = productos[i].nombre;
            }
        }
        return maxNombre;
    }
    ```

🧠 **Inicializar con datos reales, no con valores inventados.** `let max = 0` es arbitrario. `productos[0].precio` es real. Si hay al menos 1 producto, el primer elemento es siempre una referencia válida.

### E6 — `agruparPorCategoria(productos)`

!!! failure "❌ Código de Pau"

    ```js
    function agruparPorCategoria(productos) {
        let objetos = {};
        productos.forEach(item => {
            if (objetos[item.categoria] === undefined) {
                objetos[item.categoria] = [];
            }
            if (objetos[item.categoria] === "electronica") {  // ← MAL: condición muerta
                // lógica que nunca se ejecuta
            }
            objetos[item.categoria].push(item.nombre);
        })
        return objetos;
    }
    ```

Ese segundo `if` estaba comparando un array `[]` con un string literal `"electronica"`. Esa condición nunca va a ser `true`. Quedó de un intento anterior y no se limpió.

!!! success "✅ Versión corregida"

    ```js
    function agruparPorCategoria(productos) {
        let grupos = {};
        for (let i = 0; i < productos.length; i++) {
            let cat = productos[i].categoria;
            if (grupos[cat]) {
                grupos[cat].push(productos[i].nombre);
            } else {
                grupos[cat] = [productos[i].nombre];
            }
        }
        return grupos;
    }
    ```

🧠 **Objetos como diccionarios.** Si `objetos[item.categoria]` es `undefined`, lo creás. Si ya existe, le hacés push. El patrón: `if (acumulador[clave]) acumulador[clave].push(valor) else acumulador[clave] = [valor]`.

### E7 — `totalCarrito(items)`

!!! failure "❌ Código de Pau"

    ```js
    function totalCarrito(items) {
        let suma = 0;
        if (items.length === 0) return 0;
        items.forEach(producto => {
            suma += producto.precio;  // ← MAL: falta * producto.cantidad
        })
        if (suma > 100) return 0.90 * suma;
        return suma;
    }
    ```

El enunciado dice `{ nombre, precio, cantidad }`. No es `precio` solo, es `precio * cantidad` por cada item. Te saltaste `cantidad` porque asumiste el caso más simple sin leer el enunciado entero.

!!! success "✅ Versión corregida"

    ```js
    function totalCarrito(items) {
        if (items.length === 0) return 0;
        let total = 0;
        for (let i = 0; i < items.length; i++) {
            total += items[i].precio * items[i].cantidad;
        }
        if (total > 100) total -= total * 10 / 100;
        return total;
    }
    ```

🧠 **Leer el enunciado completo.** El apuro hace que veas `precio` y automáticamente pienses "sumar precios". Antes de escribir, leé **todas** las claves del objeto y asegurate de no saltarte ninguna.

### E8 — `eliminarEspacios(texto)`

**❌ Pau:** No llegó a escribirlo, se explicó el concepto.

!!! success "✅ Versión corregida"

    ```js
    function eliminarEspacios(texto) {
        let resultado = "";
        for (let i = 0; i < texto.length; i++) {
            if (texto[i] !== " ") {
                resultado += texto[i];
            } else {
                if (resultado[resultado.length - 1] !== " ") {
                    resultado += texto[i];
                }
            }
        }
        return resultado;
    }
    ```

🧠 **Construir strings incrementalmente.** `resultado += texto[i]` va agregando caracter 1 por 1. La regla del espacio múltiple: "si es espacio, solo lo agrego si el último caracter agregado NO es espacio".

## 🧠 Debilidades detectadas (patrones)

1. **Flags vs early rejection**: Insiste en flags booleanos cuando `return false` en el momento es más limpio. Apareció en E2 y `estaOrdenado`.
2. **Olvidar edge cases**: `max = 0` asume precios positivos. Siempre preguntar "¿qué pasa si...?" antes de escribir.
3. **No leer el enunciado completo**: E7 se saltó `cantidad`. Leer 2 veces antes de codificar.
4. **Construcción incremental de strings**: `resultado += texto[i]` es un patrón que cuesta visualizar pero es clave.
