## 🔴 Errores corregidos durante la sesión

| # | Error | Lección |
|---|-------|---------|
| 1 | `calmp()` en vez de `clamp()` | `calmp` no existe. Es `clamp()` |
| 2 | `focsus-visible` en vez de `focus-visible` | Typo en pseudo-clase, el browser la ignora |
| 3 | `<button><a>` anidados | Dos elementos interactivos no se anidan. Elegir uno |
| 4 | `--fs-*` usado como espaciado | Separar `--space-*` para spacing de los font-size |
| 5 | `transition: var(--c-active) ...` | `var()` de un color no es propiedad CSS válida en transition |
| 6 | `transition: all` | Especificar propiedades concretas |
| 7 | CQ exercise: `width: 200px` en contenedor estrecho y `100%` en ancho | Valores invertidos en `@container` |
| 8 | CQ exercise: `--fs-as:` sin valor | Variable incompleta corta la cadena CSS |
| 9 | `@media prefers-reduced-motion` sin paréntesis | La sintaxis es `@media (prefers-reduced-motion: reduce)` |

## 🟡 Errores que persisten

| # | Error | Lección |
|---|-------|---------|
| 1 | **Clases CSS que no matchean con HTML** | Escribe CSS con clases que no existen en el HTML. Verificar siempre |
| 2 | **Anidación BEM** | `header__nav__link` no es BEM estricto (plano sería `header__link`) |
| 3 | `cursor: pointer` en elementos no clickeables | Solo en links, botones o elementos con acción |
| 4 | `translateY(-7px)` en hover de link | Demasiado agresivo, -2px/-3px es más sutil |
