## ✅ Errores corregidos (vs 14/06)

| # | Error | Lección aprendida |
|---|-------|-------------------|
| 1 | `radial-gradient(to bottom, ...)` → `to bottom` no existe | `radial-gradient` usa `circle at center` o `ellipse`. `to bottom` es solo de `linear-gradient` |
| 2 | `font-family: sans-serif, 'Arial'` → orden invertido | Primero la fuente concreta, luego la genérica de fallback: `'Arial', sans-serif` |
| 3 | `box-shadow: 2px 5px 15px(rgba(...))` → paréntesis mal puestos | `box-shadow` NO lleva paréntesis alrededor del color. Es `offset-x offset-y blur color` |
| 4 | `border: solid grey 1px` → orden no convencional | El orden estándar es `width style color`: `1px solid grey` |
| 5 | `minmax(150px 1fr)` → falta coma | `minmax()` siempre lleva coma entre valores: `minmax(150px, 1fr)` |
| 6 | `grid-area: "header"` → comillas incorrectas | `grid-template-areas` usa strings con comillas. `grid-area` en hijos va SIN comillas |
| 7 | `display: grid` olvidado | Sin `display: grid`, `grid-template-areas` no funciona |
| 8 | `PX` mayúsculas en unidades | Siempre minúscula: `px`, `vh`, `rem`, `s` |
| 9 | Hijos del grid no directos | `grid-area` solo funciona si el elemento es HIJO DIRECTO del contenedor grid |
| 10 | `gap` olvidado, usaba `margin` | `gap` es la forma moderna y correcta. Nunca `margin` entre items de flex/grid |

## 🟡 Errores que persisten (en proceso)

| # | Error | Lección |
|---|-------|---------|
| 1 | `calc(5vh +0.8rem)` sin espacio tras operador | En `calc()` siempre espacios alrededor de `+` y `-`: `5vh + 0.8rem` |
| 2 | `rgba(0,0,0,0.5)` sin espacios tras comas | `rgba(0, 0, 0, 0.5)` — espacio después de cada coma |
| 3 | `0.5` sin cero delante: `.5s`, `.8rem` | Es válido pero mejor `0.5s`, `0.8rem` para legibilidad |
| 4 | `maxmin()` en vez de `minmax()` | No existe "maxmin", es `minmax()` |
| 5 | `display: grid` + `flex-direction` mezclados | `flex-direction` solo funciona con `display: flex`, no con grid |
