### `promptEngineer.js` — conexión base + `runPrompt` — ✅ Completado (6 fallos)

- **❌ Fallo 1:** array de mensajes declarado como variable global mutable en vez de recibido por parámetro — habría contaminado el historial entre llamadas del dataset.
- **❌ Fallo 2:** `client.await.create(...)` — confundir la keyword `await` con una propiedad del SDK.
- **❌ Fallo 3:** `stream: true` dejado de la lección de streaming, incompatible con el `.content.find(...)` de después.
- **❌ Fallo 4:** interpolar `promptInputs.altura` en vez de `.height` — los campos del dataset están en inglés, no en español.
- **❌ Fallo 5:** función y parámetro con roles invertidos, más typos (`prunPrompts`/`runPrompts` en vez de `runPrompt`).
- **❌ Fallo 6:** `addAssistantMessage` agregada sin necesitarla (el ejercicio es de un solo turno) y borrada por error junto con `addUserMessage`, que sí hacía falta.

!!! failure "❌ Fallo 1 y 2 — array global + `await` mal usado"
    ```js
    const MESSAGES = [];
    function addUserMessage(message, text){
        MESSAGES.push({role: 'user', content: text}) // ❌ ignora el parámetro, usa la global
    }

    async function chat(messages){
        const message = await client.await.create({ // ❌ "await" no es una propiedad
            model: modelo,
            max_tokens: 25000,
            stream: true, // ❌ sobrante de la lección de streaming
            messages,
        });
        return message.content.find((e) => e.type === 'text').text;
    }
    ```

!!! success "✅ Versión corregida"
    ```js
    function addUserMessage(messages, text){
        messages.push({role: 'user', content: text})
    }

    async function chat(messages){
        const message = await client.messages.create({
            model: modelo,
            max_tokens: 1000,
            messages,
        });
        return message.content.find((e) => e.type === 'text').text;
    }
    ```

🧠 **Lección:** un array declarado fuera de la función que lo usa deja de ser "el estado de esa llamada" para ser estado compartido entre todas — el mismo bug de siempre, en un contexto nuevo (llamadas a la API en vez de JS puro).
