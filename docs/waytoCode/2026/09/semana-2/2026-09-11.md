### D6 — `ByDueDateSorter` — ✅ Completado (2 fallos)

- **❌ Error 1:** comparar objetos `Task` completos en vez de sus fechas — `$b <=> $a` sobre el objeto entero en vez de `$a->getDueDate() <=> $b->getDueDate()`.
- **❌ Error 2:** `$tasks->sort()` — confundir el array con el servicio. `sort()` es un método de `TaskSorter`, no del array.

!!! success "✅ Versión corregida"
    ```php
    class ByDueDateSorter implements TaskSorter
    {
        public function sort(array $tasks): array
        {
            usort($tasks, fn($a, $b) => $a->getDueDate() <=> $b->getDueDate());
            return $tasks;
        }
    }
    ```

🧠 **Lección:** PHP pasa arrays por valor — `sort()` nunca muta el original, hay que reasignar.
