🏕️ Examen Final CSS — NomadStay

Cliente: NomadStay — plataforma de alquileres temporales para nómades digitales.

Tiempo estimado: 45–60 min.

Regla de oro: Mobile First. Base sin media query = mobile. Una sola media query min-width: 768px para desktop. Sin max-width salvo en CQ.

Archivos: nomadStay.html + nomad-styles.css. Todo desde cero.

Sección 1 — Header Flex BEM :focus-visible

.header — fondo oscuro, texto claro. Flex row. Logo a izquierda, nav centrado, botón CTA a derecha.
  • Mobile: nav links apilados (column), CTA abajo del todo.
  • Desktop (768px+): todo en una fila.
  • a11y :focus-visible en cada .header__link y .header__cta.
  • Motion Transición suave en hover de links y botón. prefers-reduced-motion debe respetarse.
  • BEM estricto: .header__logo, .header__nav, .header__link, .header__cta.

Sección 2 — Hero clamp() Variables Motion

.hero — gran titular, subtítulo, botón CTA. Una sola columna centrada.
  • Título con clamp() fluido que vaya de 2rem (móvil) a 4rem (pantalla grande).
  • Subtítulo con clamp(1rem, 2vw, 1.25rem).
  • Fondo: color primario + un degradado suave usando variables.
  • Padding vertical generoso con variable de espaciado.
  • Botón CTA con hover/transición. prefers-reduced-motion respetado.

Sección 3 — Servicios Grid BEM Variables

.services — 3 servicios en grid. Icono + título + descripción breve.
  • Mobile: 1 columna.
  • Desktop: 3 columnas iguales.
  • BEM: .services__card, .services__icon, .services__title, .services__desc.
  • Usá emojis para los iconos (🏠 🌍 💻 o los que quieras).
  • Cards con gap, padding, border-radius desde variables.
  • Transición en hover (sutil: subir 2-3px o cambiar sombra). Respetar prefers-reduced-motion.

Sección 4 — Destinos Grid auto-fit :has() CQ BEM

.destinos — grid de 6 destinos responsive SIN media queries. Cada card: imagen, título, precio, badge "Popular" (opcional).
  • Grid con repeat(auto-fit, minmax(260px, 1fr)) para que el número de columnas se adapte solo.
  • CQ Container Query: el container NO va en cada card. Va en .destinos (el grid). Esto es clave: el @container estila a los descendientes del contenedor, no al contenedor mismo.
    • .destinos tiene container: destinos-grid / inline-size.
    • Breakpoint: @container destinos-grid (min-width: 500px) — se dispara solo cuando el grid tiene 2+ columnas (escritorio).
    • Base (mobile-first, SIN container query): card en column, imagen al 100% de ancho, contenido debajo.
    • @container (min-width: 500px): card en row, imagen fija de 140px a izquierda, contenido a la derecha.
    • ¿Por qué 500px y no 320px? Con minmax(260px, 1fr), las cards miden ~260-343px tanto en mobile 1 columna como en desktop 3 columnas. Un breakpoint de 320px se dispara en ambos casos. Con 500px en .destinos (el grid), el CQ solo se activa en escritorio, donde el grid completo mide 700px+.
    • IMPORTANTE — Regla de CQ: el @container solo puede estilar descendientes del contenedor, no al contenedor mismo. Necesitás un wrapper DENTRO de .card-destinos que haga de flex container y sea el target del CQ.
  • :has() .card-destinos:has(.card__badge) debe tener un borde o color distinto para destacar.
  • BEM: .card-destinos, .card__container, .card__container--info, .card__title, .card__price, .card__badge.
  • Imagen de placeholder con background-image: https://picsum.photos/seed/ciudad/400/300.
  • Al menos 2 destinos deben tener badge "Popular".

Sección 5 — Testimonios Flex BEM :focus-visible

.testimonials — 3-4 testimonios en flex wrap.
  • Mobile: 1 columna. Desktop: 2x2 grid visual (flex con wrap).
  • Cada card: avatar (círculo), nombre, rol, texto citado.
  • Avatar con object-fit: cover, border-radius: 50%.
  • BEM: .testimonials__card, .testimonials__avatar, .testimonials__name, .testimonials__role, .testimonials__text.
  • Diseño limpio, borde sutil con border: 1px solid var(--border).

Sección 6 — Footer Grid BEM

.footer — 3 columnas: col1 = logo+desc, col2 = enlaces, col3 = contacto.
  • Mobile: 1 columna apilada.
  • Desktop: 3 columnas iguales.
  • Fondo oscuro (como el header), texto claro.
  • BEM: .footer__col, .footer__title, .footer__link, .footer__text.
  • Enlaces hover con transición.

Requisitos Globales

Variables Definí en :root: --color-primary, --color-secondary, --color-text, --color-bg, --spacing-xs, --spacing-sm, --spacing-md, --spacing-lg, --radius-sm, --radius-md, --font-body, --font-heading. Usalas en todos lados. Nada de valores mágicos.
Motion Todas las transiciones/animaciones deben respetar prefers-reduced-motion: no-preference. Si el usuario prefiere motion reducido, cero animaciones.
BEM Estricto en todo el proyecto. Sin clases sueltas, sin anidación rara.
