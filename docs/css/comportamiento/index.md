# Comportamiento { .section-comportamiento }

> Comportamientos de scroll, visualización de texto, y efectos de interacción que no son layout ni responsive.

---

## ¿Qué es "comportamiento"?

Hay propiedades CSS que no definen **dónde** se ve algo (layout), ni **cómo** responde al viewport (responsive), ni **cómo** se nombra (arquitectura). Definen **cómo se comporta** un elemento cuando el usuario interactúa:

- **scroll-snap**: controlá dónde "se pega" el scroll
- **text-wrap:balance**: equilibrá líneas de texto automáticamente
- Y más que irán apareciendo

Son detalles de UX que marcan la diferencia entre un sitio "que funciona" y uno "que se siente bien". No son obligatorios, pero cuando los necesitas, son la diferencia entre horas de JS y 3 líneas de CSS.
