1 validarPrecioEnRango(inputPrecio, spanError) ⏳ Pendiente

El alta de producto tiene un campo de precio y una línea de error justo debajo. Cada vez que se revisa el campo, el precio solo se admite si cae dentro del rango permitido: desde 10 hasta 500, con los dos extremos incluidos. Si el precio queda fuera, el usuario lee el motivo bajo el campo y el navegador tiene que dar el campo por no válido con ese mismo texto. Si el precio entra en el rango, el aviso desaparece y el campo vuelve a darse por bueno, aunque en la revisión anterior estuviera marcado como no válido.

Contrato exacto que revisa el test — la función recibe el campo #precio-s1 y el span #error-precio-s1. Con un precio fuera de rango, el texto del span no puede quedar vacío y el navegador tiene que dar el campo por no válido. Con un precio dentro de rango, el texto del span queda exactamente en cadena vacía y el navegador da el campo por válido. El test prueba 250, 9.5, 501, los dos extremos 10 y 500, y la secuencia 700 → 120 para comprobar que el campo se recupera.

Criterios de aceptación

  • 10 y 500 se admiten; 9.5 y 501 se rechazan.
  • Fuera de rango: el mensaje se ve en pantalla y el navegador da el campo por no válido con ese mismo texto.
  • Dentro de rango: el span queda en cadena vacía y el campo deja de estar marcado como no válido.
  • Pasar de un precio rechazado a uno correcto deja el formulario utilizable otra vez.

function validarPrecioEnRango(inputPrecio, spanError) {
  const precio = Number(inputPrecio.value);
  const dentroDeRango = inputPrecio.value.trim() !== '' && precio >= 10 && precio <= 500;

  if (!dentroDeRango) {
    spanError.textContent = 'El precio debe estar entre 10 y 500 EUR';
    inputPrecio.setCustomValidity(spanError.textContent);
    return;
  }

  // Rama de limpieza: sin ella el campo se queda invalido para siempre.
  spanError.textContent = '';
  inputPrecio.setCustomValidity('');
}

2 validarTelefonoExacto(inputTelefono, spanError) ⏳ Pendiente

El mismo formulario pide un teléfono de contacto. Solo se admite si tiene exactamente 9 caracteres y todos ellos son dígitos: ni 8, ni 10, ni 9 caracteres con una letra colada.   • 9 caracteres con una letra dentro también se rechazan.
  • Rechazado: mensaje visible y campo no válido para el navegador, con ese mismo texto.
  • Aceptado: span en cadena vacía y campo válido, incluso viniendo de un intento rechazado.

function validarTelefonoExacto(inputTelefono, spanError) {
  const telefono = inputTelefono.value;
  const esValido = telefono.length === 9 && telefono.trim() !== '' && !isNaN(Number(telefono));

function activarContadorConTope(botonMas, botonMenos, spanCantidad, spanRestante, minimo, maximo) {
  const pintar = (cantidad) => {
    spanCantidad.dataset.cantidad = cantidad;
    spanCantidad.textContent = cantidad;
    spanRestante.textContent = maximo - cantidad;
  };

  botonMas.addEventListener('click', () => {
    // Estado FRESCO en cada clic, y suma simple (nunca cantidad++).
    const cantidad = Number(spanCantidad.dataset.cantidad);
    pintar(Math.min(maximo, cantidad + 1));
  });

  botonMenos.addEventListener('click', () => {
    const cantidad = Number(spanCantidad.dataset.cantidad);
    pintar(Math.max(minimo, cantidad - 1));
  });
}

4 alternarDetalleAccesible(boton, detalle, flecha) ⏳ Pendiente

Un bloque de detalles plegable: un botón con su flecha y el bloque de contenido. Cada clic invierte el estado — si estaba plegado se despliega, y al revés — y el clic cuenta igual si cae sobre el texto del botón o sobre la flecha. El estado accesible del botón, la visibilidad del bloque y el dibujo de la flecha van siempre a la vez, nunca uno por su lado. Y ojo: el estado de partida lo marca el HTML, no el número de clics que lleve dada la página; si el bloque llega ya desplegado, el primer clic lo pliega.

Contrato exacto que revisa el test — desplegado significa: aria-expanded del botón en "true", #detalle-s4 sin la clase hidden y #flecha-s4 con el texto ^. El test comprueba las tres cosas a la vez tras 1, 2 y 3 clics, y además pone el bloque como desplegado desde fuera antes de un único clic para verificar que lo pliega.

Criterios de aceptación

  • Un clic desde plegado deja las tres señales en estado desplegado.
  • Dos clics vuelven al estado inicial; tres, otra vez a desplegado.
  • El clic cuenta igual si cae en el texto o en la flecha.
  • Si el HTML llega ya desplegado, el primer clic pliega (el estado se lee del propio elemento).

function alternarDetalleAccesible(boton, detalle, flecha) {
  boton.addEventListener('click', () => {
    // getAttribute devuelve TEXTO: se compara contra el string exacto.
    const abierto = boton.getAttribute('aria-expanded') === 'false';

    boton.setAttribute('aria-expanded', String(abierto));
    detalle.classList.toggle('hidden', !abierto);
    flecha.textContent = abierto ? '^' : 'v';
  });
}

function activarFiltroEtiquetas(zona) {
  zona.addEventListener('click', (e) => {
    const boton = e.target.closest('.filtro');
    if (!boton) return;

    const etiqueta = boton.dataset.etiqueta;

    // Nombres de clase SIN punto, y con force para recalcular en cada clic.
    zona.querySelectorAll('.filtro').forEach(x => {
      x.classList.toggle('filtro--activo', x === boton);
    });

    zona.querySelectorAll('.articulo').forEach(x => {
      const coincide = etiqueta === 'todos' || x.dataset.etiqueta === etiqueta;
      x.classList.toggle('hidden', !coincide);
    });
  });
}

function filtrarUsuariosPorTexto(inputBusqueda, listaUsuarios, spanResultados) {
  inputBusqueda.addEventListener('input', () => {
    const texto = inputBusqueda.value.toLowerCase().trim();
    let visibles = 0;

    listaUsuarios.querySelectorAll('.usuario').forEach(x => {
      // coincide se calcula DENTRO: se reinicia en cada vuelta.
      const nombre = x.dataset.nombre.toLowerCase();
      const correo = x.dataset.correo.toLowerCase();
      const coincide = nombre.includes(texto) || correo.includes(texto);

      x.classList.toggle('hidden', !coincide);
      if (coincide) visibles++;
    });

    spanResultados.textContent = visibles;
  });
}

function sincronizarCheckMaestro(zona) {
  const maestro = zona.querySelector('#maestro-s7');
  const estado = zona.querySelector('#estado-s7');

  zona.addEventListener('change', (e) => {
    const hijos = zona.querySelectorAll('.check-hijo');

    if (e.target === maestro) {
      // Forzar: se lee el elemento real, no una variable heredada.
      hijos.forEach(x => { x.checked = maestro.checked; });
    } else {
      // Acumular: variable local que arranca en su valor NEUTRO.
      let todasMarcadas = true;
      hijos.forEach(x => { if (!x.checked) todasMarcadas = false; });
      maestro.checked = todasMarcadas;
    }

    let marcadas = 0;
    hijos.forEach(x => { if (x.checked) marcadas++; });
    estado.textContent = marcadas;
  });
}
