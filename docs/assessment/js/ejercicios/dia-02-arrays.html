1 🟢 dobles(numeros) ⏳ Pendiente

Devuelve un array nuevo con cada número multiplicado por 2. Usá map.

map transforma cada elemento y devuelve un array nuevo de la misma longitud. Tu callback debe devolver el valor transformado — sin return te queda un array lleno de undefined.

dobles([1, 2, 3]) → [2, 4, 6]
dobles([5, 0, -2]) → [10, 0, -4]
dobles([]) → [] 
function dobles(numeros) {
  return numeros.map(n => n * 2);
}

2 🟢 preciosDe(productos) ⏳ Pendiente

Array de { nombre, precio } → array nuevo solo con los precios. Usá map.

map también sirve para extraer una propiedad de cada objeto. Es la base para armar listas de precios, títulos o IDs.

preciosDe([{nombre:"Teclado",precio:30},{nombre:"Mouse",precio:15}]) → [30, 15]
preciosDe([]) → [] 
function preciosDe(productos) {
  return productos.map(p => p.precio);

3 🟡 soloPares(numeros) ⏳ Pendiente

Devuelve solo los números pares, en el mismo orden. Usá filter.

filter conserva únicamente los elementos cuyo callback devuelve true (el predicado). La longitud del resultado puede cambiar.

soloPares([1, 2, 3, 4, 5, 6]) → [2, 4, 6]
soloPares([1, 3, 5]) → [] 
function soloPares(numeros) {
  return numeros.filter(n => n % 2 === 0);
}

4 🟡 disponibles(productos) ⏳ Pendiente

Array de { nombre, stock } → solo los productos con stock mayor que 0 (objetos completos). Usá filter.

filter con objetos elige los elementos que cumplen la condición sin modificarlos: devolvés el objeto tal cual porque el predicado solo decide quién entra.

disponibles([{nombre:"Mouse",stock:5},{nombre:"Teclado",stock:0}]) → [{nombre:"Mouse",stock:5}] 
function disponibles(productos) {
  return productos.filter(p => p.stock > 0);
}

5 🟡 totalCarrito(items) ⏳ Pendiente

Array de { nombre, precio, cantidad } → suma total de precio * cantidad. Usá forEach. Si está vacío → 0.

forEach recorre y acumula en una variable externa: no devuelve nada, el resultado sale del acumulador. Recordá que el callback de forEach no necesita return.

totalCarrito([{nombre:"Mouse",precio:25,cantidad:2},{nombre:"Teclado",precio:10,cantidad:1}]) → 60
totalCarrito([]) → 0 
function totalCarrito(items) {
  let total = 0;
  items.forEach(i => { total += i.precio * i.cantidad; });
  return total;
}

6 🔴 promedioAprobados(estudiantes) ⏳ Pendiente

Array de { nombre, nota } → promedio de notas de los que aprueban (nota >= 5). Si nadie aprueba (o array vacío) → null. Podés combinar métodos.

Combinás métodos en cadena: filter para quedarte con los aprobados, map para extraer solo las notas, y un forEach para sumar. Encadenar métodos es la forma declarativa de hacer varios pasos sobre los mismos datos.

promedioAprobados([{nombre:"Ana",nota:7},{nombre:"Luis",nota:4},{nombre:"Pau",nota:6}]) → 6.5
promedioAprobados([{nombre:"Luis",nota:4}]) → null 
function promedioAprobados(estudiantes) {
  const notas = estudiantes.filter(e => e.nota >= 5).map(e => e.nota);
  if (notas.length === 0) return null;
  let suma = 0;
  notas.forEach(n => { suma += n; });
  return suma / notas.length;
}

1 🟢 frecuenciaCaracteres(texto) ⏳ Pendiente

Devuelve un objeto con la frecuencia de cada carácter del texto. Ignorá los espacios.

Este es el patrón objeto-contador: cada clave es un carácter distinto y su valor es cuántas veces aparece. La cuenta sale del objeto, no de variables sueltas.

frecuenciaCaracteres("hola") → {h:1,o:1,l:1,a:1}
frecuenciaCaracteres("aab") → {a:2,b:1}
frecuenciaCaracteres("hola mundo") → {h:1,o:2,l:1,a:1,m:1,u:1,n:1,d:1} 
function frecuenciaCaracteres(texto) {
  let contador = {};
  for (let i = 0; i < texto.length; i++) {
    if (texto[i] === " ") continue;
    contador[texto[i]] ? contador[texto[i]]++ : contador[texto[i]] = 1;
  }
  return contador;
}

2 🟡 agruparPorLetra(palabras) ⏳ Pendiente

Devuelve un objeto que agrupa las palabras por su primera letra. Cada clave es una letra, cada valor un array de palabras. Si el array está vacío → null.

Patrón objeto-agrupador: mismo objeto que el contador pero acumulando arrays con push. Primera vez que aparece la letra, creás el array con un solo elemento.

agruparPorLetra(["hola","mundo","hielo","moto"]) → {h:["hola","hielo"],m:["mundo","moto"]}
agruparPorLetra(["a","b"]) → {a:["a"],b:["b"]}
agruparPorLetra([]) → null 
function agruparPorLetra(palabras) {
  if (palabras.length === 0) return null;
  let grupos = {};
  for (let i = 0; i < palabras.length; i++) {
    let letra = palabras[i][0];
    grupos[letra] ? grupos[letra].push(palabras[i]) : grupos[letra] = [palabras[i]];
  }
  return grupos;
}

3 🔴 ordenarPorPrecio(productos) ⏳ Pendiente

Ordena el array de { nombre, precio } de menor a mayor precio. Modificás el mismo array y lo devolvés.

Este es el doble for con swap: el for interno compara adyacentes e intercambia si toca; el for externo repite el barrido completo. Para intercambiar, guardás el que vas a pisar en una variable temporal.

ordenarPorPrecio([{nombre:"Mouse",precio:30},{nombre:"Teclado",precio:20},{nombre:"Monitor",precio:50}]) → [{nombre:"Teclado",precio:20},{nombre:"Mouse",precio:30},{nombre:"Monitor",precio:50}]
ordenarPorPrecio([{nombre:"A",precio:5},{nombre:"B",precio:3}]) → [{nombre:"B",precio:3},{nombre:"A",precio:5}] 
function ordenarPorPrecio(productos) {
  for (let j = 0; j < productos.length; j++) {
    for (let i = 1; i < productos.length; i++) {
      if (productos[i].precio < productos[i - 1].precio) {
        let temp = productos[i];
        productos[i] = productos[i - 1];
        productos[i - 1] = temp;
      }
    }
  }
  return productos;
}

V1 🟢 tieneAlgo(lista) ⏳ Pendiente

Devuelve true si el array tiene al menos un elemento, false si está vacío.

Gotcha que fallaste 2 veces: los arrays (incluso vacíos) son siempre truthy. if (lista) siempre es true, !lista siempre es false. La única forma confiable de saber si está vacío es preguntar lista.length === 0. [] == 0 es false (no confundir con coerción de strings).

tieneAlgo([1, 2]) → true
tieneAlgo([]) → false 
function tieneAlgo(lista) {
  return lista.length > 0;
}

V3 🟡 sumarEdades(edades) ⏳ Pendiente

Suma todos los números del array con reduce.

reduce recorre el array y va acumulando en un solo valor. acumulador = el valor que se va construyendo; item = cada elemento. El valor inicial (0) es el acumulador de partida. IMPORTANTE: sin valor inicial, reduce usa el primer elemento como acumulador inicial y arranca desde el segundo — y truena en array vacío.

sumarEdades([15, 22, 30]) → 67
sumarEdades([]) → 0 
function sumarEdades(edades) {
  return edades.reduce((acum, edad) => acum + edad, 0);
}

V4 🔴 precioTotalPerecederos(items) ⏳ Pendiente

Array de { nombre, precio, tipo } → suma de precios SOLO de los de tipo "perecedero". Con reduce.

Combina el poder del reduce: el acumulador no tiene por qué ser solo una suma simple — podés poner una condición dentro del callback. Patrón: filtro "implícito" dentro de reduce (ya lo usaste con forEach en promedioAprobados).

precioTotalPerecederos([{nombre:"Manzana",precio:2,tipo:"perecedero"},{nombre:"Arroz",precio:5,tipo:"seco"}]) → 2
precioTotalPerecederos([]) → 0 
function precioTotalPerecederos(items) {
  return items.reduce((acum, item) => {
    if (item.tipo === "perecedero") acum += item.precio;
    return acum;
  }, 0);
}

V5 🔴 contarPorCategoria(productos) ⏳ Pendiente

Array de { nombre, categoria } → objeto con el conteo de productos por categoría. Con reduce.

Mismo patrón mental que frecuenciaCaracteres/agruparPorLetra (objeto-contador), pero ahora el acumulador de reduce es el objeto en sí — arranca en {} en vez de 0. El return acum tiene que salir en TODAS las ramas.

contarPorCategoria([{nombre:"Manzana",categoria:"fruta"},{nombre:"Pan",categoria:"panaderia"},{nombre:"Banana",categoria:"fruta"}]) → {fruta:2,panaderia:1}
contarPorCategoria([]) → {} 
function contarPorCategoria(productos) {
  return productos.reduce((acum, item) => {
    if (acum[item.categoria]) acum[item.categoria]++;
    else acum[item.categoria] = 1;
    return acum;
  }, {});
}
