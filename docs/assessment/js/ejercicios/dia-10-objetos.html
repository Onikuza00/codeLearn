1 🟢 contarPropiedades(objeto) ⏳ Pendiente

Devuelve cuántas propiedades tiene el objeto. Usá Object.keys.

Object.keys devuelve un array con las claves — de ahí sacás .length, igual que contarías elementos en cualquier array.

contarPropiedades({a:1, b:2, c:3}) → 3
contarPropiedades({}) → 0 
function contarPropiedades(objeto) {
  return Object.keys(objeto).length;
}

2 🟢 tieneValor(objeto, valorBuscado) ⏳ Pendiente

Devuelve true si algún valor del objeto es igual a valorBuscado. Usá Object.values + algún método de array (pista: no es forEach).

Object.values te da un array de valores — a partir de ahí es el mismo problema que "¿este array contiene X?" que ya resolviste con arrays de números.

tieneValor({a:1, b:2}, 2) → true
tieneValor({a:1, b:2}, 5) → false 
function tieneValor(objeto, valorBuscado) {
  return Object.values(objeto).includes(valorBuscado);
}

3 🟡 clavesConValor(objeto, valorBuscado) ⏳ Pendiente

Devuelve un array con las claves cuyo valor sea exactamente valorBuscado. Usá Object.entries.

Object.entries te da pares [clave, valor]. Filtrás los pares donde el valor coincide, y te quedás solo con la clave de cada par que sobrevivió.

clavesConValor({a:true, b:false, c:true}, true) → ["a", "c"]
clavesConValor({a:1, b:2}, 5) → [] 
function clavesConValor(objeto, valorBuscado) {
  return Object.entries(objeto)
    .filter(([clave, valor]) => valor === valorBuscado)
    .map(([clave, valor]) => clave);
}

4 🟢 datosPersona(persona) ⏳ Pendiente

Recibe { nombre, edad }. Si no tiene edad, usá 30 por defecto. Devuelve "${nombre} tiene ${edad} años". Usá destructuring con valor por defecto.

Destructuring con valor por defecto: const { nombre, edad = 30 } = persona. El default solo se aplica si la propiedad es undefined (no existe), no si es 0 o false.

datosPersona({nombre:"Pau", edad:24}) → "Pau tiene 24 años"
datosPersona({nombre:"Ana"}) → "Ana tiene 30 años" 
function datosPersona(persona) {
  const { nombre, edad = 30 } = persona;
  return `${nombre} tiene ${edad} años`;
}

5 🟡 ciudadSegura(persona) ⏳ Pendiente

Devuelve persona.direccion.ciudad. Si persona no tiene direccion, devolvé "Desconocida" en vez de explotar. Usá optional chaining ?..

persona?.direccion?.ciudad corta en el primer undefined/null de la cadena y devuelve undefined sin tirar error. Combinalo con ?? o un operador ternario para poner el valor por defecto.

ciudadSegura({direccion:{ciudad:"Girona"}}) → "Girona"
ciudadSegura({nombre:"Pau"}) → "Desconocida" 
function ciudadSegura(persona) {
  return persona?.direccion?.ciudad ?? "Desconocida";

6 🟡 actualizarEdad(persona, nuevaEdad) ⏳ Pendiente

Devuelve un objeto nuevo igual a persona pero con edad actualizada. NO mutes persona. Usá spread.

"No mutar, crear nuevo" aplicado a objetos: { ...persona, edad: nuevaEdad } copia todas las propiedades y pisa edad con el nuevo valor. Revisá con console.log(persona) después de llamar tu función que el original sigue intacto.

actualizarEdad({nombre:"Pau", edad:24}, 25) → {nombre:"Pau", edad:25}
actualizarEdad({nombre:"Ana", edad:30}, 31) → {nombre:"Ana", edad:31} 
function actualizarEdad(persona, nuevaEdad) {
  return { ...persona, edad: nuevaEdad };
}

Consolidación del bloque: un sistema de puntuación es un objeto { jugador: puntos }. Las 4 funciones combinan spread, Object.entries, Object.values y destructuring con optional chaining — todo lo de hoy, en un solo mini-sistema.

P1 🟢 sumarPuntos(sistema, jugador, puntos) ⏳ Pendiente

Devuelve un sistema nuevo con los puntos de jugador incrementados. Si el jugador no existe todavía, se crea arrancando en 0. NO mutes sistema. Usá spread.

Mismo patrón que actualizarEdad (E6), pero la clave a actualizar es dinámica (viene de una variable, no la escribís literal) — necesitás notación de corchetes dentro del spread: { ...sistema, [jugador]: nuevoValor }.

sumarPuntos({ana:15}, "ana", 5) → {ana:20}
sumarPuntos({ana:15}, "bruno", 5) → {ana:15, bruno:5} 
function sumarPuntos(sistema, jugador, puntos) {
  const actual = sistema[jugador] ?? 0;
  return { ...sistema, [jugador]: actual + puntos };
}

P2 🟡 jugadorGanador(sistema) ⏳ Pendiente

Devuelve el nombre del jugador con más puntos. Si el sistema está vacío, devolvé null. Usá Object.entries.

Recorré los pares [jugador, puntos] con reduce (o un for), quedándote con el par de mayor puntos, y al final devolvé solo el nombre (posición 0). Es el mismo problema que "buscar el máximo", solo que sobre pares en vez de números sueltos.

jugadorGanador({ana:15, bruno:22, carla:8}) → "bruno"
jugadorGanador({}) → null 
function jugadorGanador(sistema) {
  const pares = Object.entries(sistema);
  if (pares.length === 0) return null;
  const ganador = pares.reduce((mejor, actual) =>
    actual[1] > mejor[1] ? actual : mejor
  );
  return ganador[0];
}

P3 🟡 promedioPuntos(sistema) ⏳ Pendiente

Devuelve el promedio de puntos de todos los jugadores. Si el sistema está vacío, devolvé 0. Usá Object.values.

Object.values te da un array de números — de ahí en más es exactamente sumarEdades/promedioAprobados que ya resolviste con arrays, solo que la fuente de datos es un objeto en vez de un array de partida.

promedioPuntos({ana:10, bruno:20}) → 15
promedioPuntos({}) → 0 
function promedioPuntos(sistema) {
  const valores = Object.values(sistema);
  if (valores.length === 0) return 0;
  const suma = valores.reduce((acum, n) => acum + n, 0);
  return suma / valores.length;
}

P4 🟡 perfilJugador(jugador) ⏳ Pendiente

Recibe { nombre, puntos, equipo } (equipo es opcional). Devuelve "nombre: puntos pts (equipo)", o "(sin equipo)" si no tiene equipo. Combiná destructuring con optional chaining.

Este junta E4 (destructuring) y E5 (optional chaining/??) en un solo ejercicio: desestructurá nombre y puntos directo, y para equipo usá ?? con el texto por defecto.

perfilJugador({nombre:"Ana", puntos:15, equipo:"Rojo"}) → "Ana: 15 pts (Rojo)"
perfilJugador({nombre:"Bruno", puntos:22}) → "Bruno: 22 pts (sin equipo)" 
function perfilJugador(jugador) {
  const { nombre, puntos, equipo } = jugador;
  return `${nombre}: ${puntos} pts (${equipo ?? "sin equipo"})`;
}
