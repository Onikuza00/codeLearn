1 🟢 ejecutarSiPositivo(numero, callback) ⏳ Pendiente

Si numero es mayor que 0, ejecutá callback(numero) y devolvé su resultado. Si no, devolvé null.

Es el patrón base de un callback: no sabés qué hace la función que te pasan, solo la ejecutás en el momento correcto — callback(numero), con paréntesis, nunca callback a secas.

ejecutarSiPositivo(5, n => n * 2) → 10
ejecutarSiPositivo(-3, n => n * 2) → null 
function ejecutarSiPositivo(numero, callback) {
  if (numero <= 0) return null;
  return callback(numero);
}

2 🟢 repetir(n, callback) ⏳ Pendiente

Ejecutá callback(i) para cada i desde 0 hasta n - 1, y devolvé un array con todos los resultados.

Mismo resultado que map, pero armado a mano con un for — para ver que map no es magia: es exactamente esto, un loop que llama tu callback en cada vuelta y junta los resultados en un array nuevo.

repetir(3, i => i * i) → [0, 1, 4]
repetir(0, i => i) → [] 
function repetir(n, callback) {
  const resultado = [];
  for (let i = 0; i < n; i++) {
    resultado.push(callback(i));
  }
  return resultado;
}

3 🟡 crearContador() ⏳ Pendiente

Devolvé una función que, cada vez que la llamás, incrementa un contador interno en 1 y devuelve el valor actualizado. Arranca en 0.

Es el ejemplo exacto de la teoría (demo en vivo de Funciones). El contador vive en el scope de crearContador() y la función que devolvés lo "recuerda" entre llamadas — eso es un closure.

const contar = crearContador();
contar() → 1
contar() → 2
contar() → 3 
function crearContador() {
  let contador = 0;
  return function () {
    contador++;
    return contador;
  };
}

4 🟡 crearContadorDesde(inicio) ⏳ Pendiente

Igual que crearContador(), pero el contador arranca en inicio en vez de 0.

El closure no solo recuerda variables declaradas ADENTRO de la función — también recuerda sus parámetros. inicio queda "capturado" igual que contador en el ejercicio anterior.

const contar = crearContadorDesde(10);
contar() → 11
contar() → 12 
function crearContadorDesde(inicio) {
  let contador = inicio;
  return function () {
    contador++;
    return contador;
  };
}

5 🟡 crearMultiplicador(factor) ⏳ Pendiente

Devolvé una función que reciba un número y lo multiplique por factor.

Patrón "función de fábrica" — como crearSaludo(saludo) de la teoría, pero configurando una operación matemática en vez de un texto.

const porTres = crearMultiplicador(3);
porTres(4) → 12
porTres(5) → 15 
function crearMultiplicador(factor) {
  return function (numero) {
    return numero * factor;
  };
}

6 🔴 crearAcumulador() ⏳ Pendiente

Devolvé una función que reciba un número, lo sume a un total interno (arranca en 0), y devuelva el total actualizado.

Mismo patrón que crearContador, pero acumulando el valor que le pasás en vez de sumar siempre 1 — conecta con reduce (Fallo 15, GOTCHAS.md): acá el acumulador vive "guardado" en el closure, en vez de pasar de vuelta en vuelta dentro de un solo loop.

const acumular = crearAcumulador();
acumular(5) → 5
acumular(3) → 8
acumular(10) → 18 
function crearAcumulador() {
  let total = 0;
  return function (numero) {
    total += numero;
    return total;
  };
}
