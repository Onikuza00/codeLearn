⚡ Examen JS — Fundamentos

Contexto: 8 ejercicios cortos de JavaScript vanilla. Sin DOM, sin fetch, sin librerías. Solo lógica pura.

Tiempo estimado: 20–30 min.

Reglas: const por defecto, let solo si reasignas. Nada de var. Early returns. Sin IA, sin copiar.

Formato: Escribe cada función en un archivo basico.js. Puedes ir probando con console.log().

⚡ 8 ejercicios ⏱ 20–30 min 🎯 6/8 para aprobar 📁 basico.js

1 — Hola, mundo Función

Crea una función saludar(nombre) que reciba un nombre y devuelva "Hola, " + nombre + "!".
  • Si no se pasa nombre, debe devolver "Hola, desconocido!".
  • Usa un parámetro por defecto.
// Ejemplo:
saludar("Ana")   // → "Hola, Ana!"
saludar()        // → "Hola, desconocido!"

2 — ¿Es mayor de edad? Condicional

Crea una función esMayor(edad) que devuelva true si la edad es 18 o más, y false en caso contrario.
  • Si la edad es menor que 0 o no es un número, devuelve null.
  • Usa un early return para los casos inválidos.
// Ejemplo:
esMayor(20)   // → true
esMayor(15)   // → false
esMayor(-5)   // → null

3 — Números pares Bucles Arrays

Crea una función numerosPares(n) que reciba un número n y devuelva un array con los números pares desde 0 hasta n (incluyendo n si es par).
  • Usa un bucle for.
  • Si n es menor que 0, devuelve un array vacío.
// Ejemplo:
numerosPares(10)  // → [0, 2, 4, 6, 8, 10]
numerosPares(7)   // → [0, 2, 4, 6]
numerosPares(-3)  // → []

4 — Sumar array Bucles Arrays

Crea una función sumarArray(numeros) que reciba un array de números y devuelva la suma total.
  • Si el array está vacío, devuelve 0.
  • Puedes usar un bucle for clásico o for...of.
// Ejemplo:
sumarArray([1, 2, 3, 4, 5])  // → 15
sumarArray([])                // → 0
sumarArray([10, -2, 8])      // → 16

5 — Invertir texto String Métodos

Crea una función invertirTexto(texto) que devuelva el texto al revés.
  • No uses reverse() de arrays — hazlo con un bucle.
  • Si el texto está vacío o no es un string, devuelve "".
// Ejemplo:
invertirTexto("hola")  // → "aloh"
invertirTexto("JS")    // → "SJ"
invertirTexto("")      // → ""

6 — Contar vocales String Bucles

Crea una función contarVocales(texto) que devuelva el número de vocales (a, e, i, o, u) en un string.
  • Debe contar tanto mayúsculas como minúsculas.
  • Ignora acentos (asume texto sin acentos).
  • Si el texto está vacío, devuelve 0.
// Ejemplo:
contarVocales("Hola mundo")  // → 4  (o, a, u, o)
contarVocales("JavaScript")  // → 3  (a, a, i)
contarVocales("")            // → 0

7 — Encontrar el mayor Arrays Bucles

Crea una función encontrarMayor(numeros) que devuelva el número más grande de un array.
  • Si el array está vacío, devuelve null.
  • No uses Math.max() — hazlo con un bucle.
  • Usa un early return para el caso vacío.
// Ejemplo:
encontrarMayor([3, 7, 2, 9, 5])  // → 9
encontrarMayor([-5, -2, -8])     // → -2
encontrarMayor([])               // → null

8 — FizzBuzz Bucles Condicional

Crea una función fizzBuzz(n) que imprima los números del 1 al n con estas reglas:
  • Si el número es múltiplo de 3, imprime "Fizz".
  • Si es múltiplo de 5, imprime "Buzz".
  • Si es múltiplo de ambos (3 y 5), imprime "FizzBuzz".
  • Si no, imprime el número.
  • La función debe devolver un array con los resultados.
// Ejemplo:
fizzBuzz(5)
// → [1, 2, "Fizz", 4, "Buzz"]

fizzBuzz(15)
// → [1, 2, "Fizz", 4, "Buzz", "Fizz", 7, 8, "Fizz", "Buzz", 11, "Fizz", 13, 14, "FizzBuzz"]
⏱️ Prioriza en orden. Si te atascas en uno, pasa al siguiente. 6/8 para aprobar. El 8 (FizzBuzz) es el más difícil.
