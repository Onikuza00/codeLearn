Cómo trabajar estos ejercicios.

  • Todos se hacen en tu terminal, dentro de una carpeta local, con un entorno virtual (python -m venv .venv) activado. No hace falta ningún framework ni navegador.
  • Cada ejercicio es un archivo propio: ejercicios/ex01.py, ex02.py… Lo ejecutas con python ex01.py.
  • Si quieres comprobar tu solución con pruebas, puedes usar pytest de forma opcional.
  • La solución está oculta tras un botón. Inténtalo antes de abrirla.
  • 🟢 fácil · 🟡 medio. Los ejercicios irán de menos a más dentro de cada bloque.

Sin ejercicios todavía: se añadirán por tandas, la más nueva primero.
