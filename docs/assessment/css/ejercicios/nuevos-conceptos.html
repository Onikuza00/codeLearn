1 🟢 @container — Container Queries ⏳ Pendiente

Hacé que una .card cambie a fondo oscuro cuando su contenedor mida más de 400px de ancho.

💡 Repaso del fallo del 25/07: container NO se estila a sí mismo

<div class="card-wrapper">
  <div class="card">Card</div>
</div>
/* wrapper 300px → .card fondo blanco */
/* wrapper 500px → .card fondo #1a1a2e */ 
/* ❌ Error clásico: container en la misma card */
.card { container-type: inline-size; }
@container (min-width: 400px) {
  .card { background: #1a1a2e; } /* ❌ .card no es descendiente de sí misma */
}

/* ✅ Correcto: container en el WRAPPER, .card es descendiente */
.card-wrapper { container-type: inline-size; }
@container (min-width: 400px) {
  .card { background: #1a1a2e; }
}
🔑 @container solo afecta a descendientes del contenedor. El container query nunca puede estilar al contenedor mismo. Poné container-type en un wrapper, y @container apunta a los hijos.
2 🟡 :has() — Formularios con feedback visual ⏳ Pendiente

Cambiá el borde de un .form-group a verde cuando su input esté en foco.

💡 Repaso de :has() del 25/07 — conectar padre e hijo sin JS

<div class="form-group">
  <label>Email</label>
  <input type="email">
</div>
/* input sin foco → .form-group borde gris */
/* input :focus → .form-group borde verde */ 
/* ❌ Pau: estilar el input directamente */
.form-group input:focus { border-color: #4ade80; }

/* ✅ Con :has() estilás el PADRE cuando el hijo tiene foco */
.form-group:has(input:focus) {
  border-color: #4ade80;
  box-shadow: 0 0 8px rgba(74, 222, 128, 0.3);
}
🔑 :has() permite estilar un elemento según el estado de sus hijos. No hace falta JS para feedback visual en formularios.
3 🟡 & — CSS Nesting nativo ⏳ Pendiente

Reescribí este CSS plano usando nesting nativo con &.

💡 Nuevo: CSS Nesting está soportado en navegadores modernos

/* CSS plano para anidar */
.card { }
.card__title { }
.card__title:hover { }
.card__body { }
.card--featured { }
/* Usá & para referirte al padre dentro del bloque */ 
/* ❌ Sin nesting — selectores planos */
.card { }
.card__title { }
.card__title:hover { }
.card__body { }
.card--featured { }

/* ✅ Nesting nativo */
.card {
  &__title { }
  &__title:hover { }
  &__body { }
  &--featured { }
}
🔑 CSS Nesting (&) funciona como Sass pero sin compilador. El & se reemplaza por el selector padre. &__title → .card__title. No necesitás Sass.
4 🔴 @layer — Control de cascada ⏳ Pendiente

Creá tres capas en orden: base, components, utilities. La clase .btn-primary debe ganar siempre aunque el selector de components sea menos específico.

💡 Nuevo: @layer da control total sobre el orden de cascada

/* En components: */
.btn { background: gray; }

/* En utilities: */
.bg-primary { background: blue; }
/* <button class="btn bg-primary"> → debe ganar bg-primary pese a tener misma especificidad */
/* Si utilities va última, .bg-primary gana a .btn */ 
/* ❌ Sin @layer: el orden en el archivo decide (frágil) */
.btn { background: gray; }
.bg-primary { background: blue; } /* gana porque va después */

/* ✅ Con @layer: orden explícito */
@layer base, components, utilities;

@layer components {
  .btn { background: gray; }
}

@layer utilities {
  .bg-primary { background: blue; }
}

/* utilities gana porque se declaró última en @layer */
🔑 @layer gana a la especificidad normal. La capa declarada ÚLTIMA gana aunque los selectores tengan la misma especificidad. Ideal para utilities que siempre deben sobreescribir.
5 🟢 scroll-snap — Slider horizontal ⏳ Pendiente

Creá un slider horizontal de cards que "snappe" a cada card al hacer scroll.

💡 Nuevo: scroll-snap sin JS — CSS nativo

<div class="slider">
  <div class="slide">1</div>
  <div class="slide">2</div>
  <div class="slide">3</div>
</div>
/* Scroll horizontal, cada slide de 300px, snap al centro */ 
/* ❌ Pau: slider sin snap o con JS */
.slider {
  display: flex;
  overflow-x: auto;
}
.slide { min-width: 300px; }

/* ✅ Con scroll-snap nativo */
.slider {
  display: flex;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
}
.slide {
  min-width: 300px;
  scroll-snap-align: center;
}
🔑 scroll-snap-type en el contenedor define la dirección y si es obligatorio. scroll-snap-align en los hijos define dónde "snappean" (start, center, end). Sin JS.
6 🟡 text-wrap — Títulos equilibrados ⏳ Pendiente

Un título de 2 líneas como "Transformá tu presencia online con diseño moderno" debe partirse de forma equilibrada.

💡 Nuevo: text-wrap:balance evita viudas y不均等

<h1 class="hero__title">
  Transformá tu presencia online con diseño moderno
</h1>
/* Sin text-wrap: 1 palabra suelta en segunda línea */
/* Con text-wrap:balance → 3 y 3 palabras o similar */ 
/* ❌ Sin text-wrap: el navegador corta donde quiere */
.hero__title { font-size: 2.5rem; }

/* ✅ Con text-wrap: el navegador equilibra las líneas */
.hero__title {
  font-size: 2.5rem;
  text-wrap: balance;
  max-width: 20ch; /* opcional: controlar ancho */
}

/* Tip: text-wrap:pretty es menos agresivo que balance */
🔑 text-wrap: balance hace que el navegador elija el mejor punto de quiebre para que todas las líneas tengan longitud similar. Adiós a las viudas (1 palabra sola en la última línea).
7 🟡 subgrid — Alinear grids anidados ⏳ Pendiente

Dos cards dentro de un grid de 2 columnas. Cada card tiene título + descripción. Usá subgrid para que las descripciones se alineen entre sí.

💡 Nuevo: subgrid hereda las tracks del grid padre

<div class="grid">
  <div class="card">
    <h3>Título</h3>
    <p>Descripción</p>
  </div>
  (...)
</div>
/* grid padre: 2 columnas iguales */
/* .card usa subgrid para que filas de título y descripción se alineen */ 
/* ❌ Sin subgrid: cada card tiene su propio grid interno */
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr;
}
.card {
  display: grid;
  grid-template-rows: auto 1fr;  /* cada card independiente */
}

/* ✅ Con subgrid: hereda rows del padre */
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr;
  grid-template-rows: auto 1fr;
}
.card {
  display: grid;
  grid-row: span 2;         /* cada card ocupa 2 filas */
  grid-template-rows: subgrid;  /* hereda tracks del padre */
}
🔑 subgrid hace que elementos hijos se alineen con el grid del abuelo. El padre define las tracks, el hijo usa grid-template-rows: subgrid en vez de valores fijos. Perfecto para cards que deben mantener alineación horizontal.
8 🟢 calc() + Variables — Sistema de espaciado ⏳ Pendiente

Usando una variable base --space: 0.5rem, creá las variables --s-1 a --s-4 multiplicando con calc().

💡 Repaso: variables + calc para sistemas consistentes

/* ⚡ Sin valores mágicos, todo desde una variable base */
/* --s-1 = 0.5rem */
/* --s-2 = 1rem */
/* --s-3 = 2rem */
/* --s-4 = 4rem */ 
/* ❌ Pau: valores mágicos hardcodeados */
:root {
  --s-1: 0.5rem;
  --s-2: 1rem;
  --s-3: 2rem;
  --s-4: 4rem;
}

/* ✅ Con calc() desde una variable base */
:root {
  --space: 0.5rem;
  --s-1: calc(--space * 1);  /* 0.5rem */
  --s-2: calc(--space * 2);  /* 1rem */
  --s-3: calc(--space * 4);  /* 2rem */
  --s-4: calc(--space * 8);  /* 4rem */
}

/* Beneficio: cambiando --space: 0.25rem escalás todo el sistema */
🔑 calc() + variables = sistema de espaciado escalable. Cambiás un solo valor y todo se actualiza. Adiós a valores mágicos. La convención de múltiplos de 2 (1, 2, 4, 8) mantiene consistencia visual.
