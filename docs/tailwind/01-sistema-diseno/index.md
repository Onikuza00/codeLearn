# Sistema de diseño { .bloque-tailwind }

> Los tokens que sostienen casi todas las clases del día a día: espaciado, tamaños, colores y tipografía. Todos comparten el mismo mecanismo — una escala consistente, no valores libres.

---

## ¿Qué es un token de diseño?

Un valor reutilizable (un espaciado, un color, un tamaño de fuente) definido una sola vez y referenciado por nombre en vez de repetido como número mágico en cada regla. Tailwind trae una escala de tokens ya definida por defecto, y personalizable vía `@theme`.
