# Fundamentos { .bloque-tailwind }

> El cambio de mentalidad antes que las clases: por qué existe Tailwind, cómo se instala y cómo leer una utility class antes de escribir la primera.

---

## ¿Qué problema resuelve?

Escribiendo CSS tradicional, cada componente nuevo obliga a inventar un nombre de clase y a escribir sus reglas en un archivo aparte. Con el tiempo esas reglas se acumulan, se pisan entre sí y nadie se anima a borrar CSS "por si acaso" se usa en algún sitio.

Tailwind cambia el punto de partida: en vez de escribir CSS, compones el diseño con clases utilitarias ya definidas directamente en el HTML.
