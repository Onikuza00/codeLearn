# 🤖 IA

Aprendizaje y práctica trabajando con asistentes de IA para programar — no como autocompletado, sino como herramienta que hay que saber dirigir, configurar y verificar.

- [Claude](claude/index.md) — Claude Code: cómo dirigir sesiones largas, configurarlo, automatizar tareas repetidas y verificar lo que hace sin supervisión directa. Incluye el [glosario de comandos](claude/00-glosario/index.md) y la [API de Claude](claude/02-claude-api/index.md).
- [IA local](local/index.md) — ejecutar modelos en tu propia máquina o servidor: conceptos (parámetros, cuantización, contexto), Ollama, Open WebUI y cómo configurarlo para varias personas sin dejarlo abierto.
